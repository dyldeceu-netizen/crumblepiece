# CrumblePiece

Link page for [crumblepiece.com](https://crumblepiece.com), hosted on GitHub Pages.
The page is grandpa's living room in PSX style. Tap the family photo to pet Ziggy.

- Links and texts: `index.html`
- Styles: `css/style.css`. Pet counter and sounds: `js/main.js`
- Images: renders from the channel's own scenes (`images/`). The wallpaper, floor, knit, doormat and crayon drawing are the
  real set textures (`images/tex/`).
- Sounds: `sounds/purr.mp3` and `sounds/meow.mp3`, short cuts of Pixabay sound effects
- Fonts: Anton and Nunito (SIL Open Font License), self-hosted in `fonts/`

The first version was based on [LittleLink](https://github.com/sethcottle/littlelink) (MIT, see `LICENSE.md`).
